# 手動驗證清單（部署後在實機執行）

自動測試用的是記憶體假 API；以下項目要用真的 Apps Script 與 GitHub Pages 驗收。

## 發布與設定
- [ ] Settings → Pages → Source 為「GitHub Actions」，`main` 推送後 Actions 全綠並部署成功。
- [ ] 開 `https://unnn3ing-oss.github.io/hottopic/`，開發者工具 Console **沒有** `Refused to …`（CSP 違規）。
- [ ] `curl -I https://unnn3ing-oss.github.io/hottopic/` 記下 `cache-control`（頁面快取時間），確認 `?v=` 資源更新有生效。
- [ ] Worker 已部署，`curl` 驗證 `/login`、`/api` 的 `ping` 都成功（見 README），之後才併入網頁 PR。
- [ ] 設定視窗：貼上 Worker 網址與登入密碼 → 登入成功；故意貼錯密碼 → 顯示「密碼不正確」；貼錯網址（非 `workers.dev`）→ 顯示網址格式錯誤。
- [ ] 重新整理後需要重新登入（未勾記住）；勾「記住登入」後重新整理直接載入列表；瀏覽器 localStorage 內找不到密碼本身。
- [ ] 12 小時到期：登入後超過 12 小時再操作 → 自動跳出設定視窗並提示登入已過期（可暫時把 Worker 的 `SESSION_SECRET` 換掉來模擬）。
- [ ] 密碼輪替：改 Worker 的 `APP_PASSWORD` → 新密碼可登入、舊密碼被拒；`API_TOKEN` 兩邊不一致時，操作會顯示「Worker 與後端的密碼設定不一致」。
- [ ] 手機實機（iPhone Safari、Android Chrome）：登入、記住登入、重新整理後仍在登入狀態。

## 功能
- [ ] 新增：貼網址 → 自動帶入原始標題與來源；抓不到時顯示提示且仍可儲存。
- [ ] 重複網址 → 顯示「已存在」並可轉為編輯。
- [ ] 編輯分類、小編文、改標（新增／移除／修改）；既有版本的使用紀錄保留。
- [ ] 刪除：兩段式確認；試算表「新聞」「改標」兩個分頁的對應列都清掉。
- [ ] 標記已使用：兩段式確認；試算表整則與該版本的時間、次數都更新。
- [ ] 複製標題（多版時為目前版本）與複製留言：貼到 IG、Threads 檢查換行與 emoji。
- [ ] 先按「複製標題」再按「複製留言」：自動記為已使用（記在複製的那一版）；只按其中一個、順序相反、或中間換了別篇，都不會記。
- [ ] 改標：滑動、拖曳、圓點、方向鍵、滑鼠移到卡片上的 ‹ › 都能換版；手機寬度先看清單，點進去才顯示卡片，左上角 ‹ 返回。
- [ ] 在試算表手動新增分類、新增一則改用的分類 → 網頁重新整理後出現在篩選列。

## 版面與效能
- [ ] 手機：版面無橫向溢出，手指左右滑動換版、一次只換一版。
- [ ] 電腦：滑鼠拖曳、觸控板橫滑、方向鍵、‹ › 都可換版。
- [ ] 冷啟動延遲：閒置 10 分鐘以上後第一次操作的等待時間（記錄數字）。
- [ ] 連線中斷時（關閉網路再按「標記已使用」）：顯示「連線中斷，結果不確定，已重新載入列表」，不重複寫入。

## 送到套版（需 Chrome 實機 + 擴充功能「圖片套版產生器」4.50 以上）
自動測試用的是假的橋接；真的擴充功能只能在 Chrome 實測。請先確認 QuickPatterntool 的分支已併入 `main`，再做以下項目。
- [ ] 擴充功能側邊欄按「更新」更新到 4.50（會跳「會增加權限」確認，同意），然後**重新整理**已開著的熱門新聞庫分頁。
- [ ] 側邊欄開著時，在卡片按「送到套版」→ 網址自動帶入並完成快速產圖；圖上標題是卡片**目前顯示**的那版改標（輪播到第 2 版再按，就是第 2 版）；按鈕停在「直接下載」，沒有自動下載。
- [ ] 側邊欄關著時按「送到套版」→ 觀察結果並回報：① 側邊欄自動打開並產圖，或 ② 圖示出現藍色「1」，點圖示打開側邊欄後自動產圖。（**這是 spec §11 的未驗證項：Chrome 是否承認經由訊息轉送的 `sidePanel.open`。**） 擴充功能已在驗證通過後立刻同步呼叫 `sidePanel.open`，但「頁面點擊 → postMessage → 內容腳本 → background」這條鏈 Chrome 是否算使用者操作，只能實測。
- [ ] 按了「送到套版」卻很久（超過 2 分鐘）才點圖示 → 不會自動產圖（請求已過期被丟棄）。
- [ ] 連按兩則不同新聞 → 側邊欄以最後一則為準。
- [ ] 文章抓不到圖或逾時 → 圖上仍有卡片的改標，狀態列顯示原有的失敗原因，可手動放圖。
- [ ] 沒裝擴充功能（或舊版、或沒重新整理分頁）的瀏覽器按按鈕 → 約 1 秒內提示「沒偵測到套版擴充功能…」，網址已在剪貼簿。
- [ ] 新聞網址不是 `tvbs.com.tw`（例如試算表裡手動改成別的網域）→ 被拒絕並複製網址，側邊欄沒有動作。
- [ ] 按「送到套版」前後，該則新聞的「上次使用／次數」都沒有變。
- [ ] 圖示若沒釘選在工具列，藍色「1」看不到：點拼圖選單裡的擴充功能能否打開側邊欄並自動產圖？
- [ ] 慢的電腦、擴充功能閒置很久後第一次按：是否會先跳「沒偵測到套版擴充功能」但側邊欄其實已經打開？（卡片只等 800 毫秒的 ack；若常發生要改成先回「已收到」）
- [ ] 開著多個 Chrome 視窗、各自開著側邊欄時送出：只有一個在產圖，還是都產？
